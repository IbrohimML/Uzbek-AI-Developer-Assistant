
# Uzbek AI Developer Assistant

Uzbek tilida ishlaydigan RAG (Retrieval-Augmented Generation) asosidagi AI yordamchi.

## Features

- Uzbek language question answering
- Semantic search
- RAG architecture
- BAAI/bge-m3 embeddings
- ChromaDB vector database
- Ollama local LLM (Gemma)
- Telegram bot integration
- Chat history support
- Context-based answers

## Tech Stack

- Python
- PyTorch
- Sentence Transformers
- ChromaDB
- LangChain Text Splitters
- Ollama
- python-telegram-bot
